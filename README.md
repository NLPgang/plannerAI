# 📅 AI Planner & Scheduler Backend + Bot

Асинхронная интеллектуальная система для автоматического планирования задач и управления календарем на основе анализа естественного языка (NLP). Проект включает в себя производительный REST API бэкенд и интерфейс в виде Telegram-бота.

## 🚀 Основной функционал

- **NLP Parsing:** Автоматическое извлечение дедлайнов, задач и событий из неструктурированного текста пользователя с помощью интеграции с моделями OpenAI.
- **Calendar Automation:** Генерация и экспорт событий в стандартный формат `iCalendar (.ics)` для синхронизации с Google Calendar, Apple Calendar и Outlook.
- **Smart Datetime Extraction:** Распознавание сложных относительных временных конструкций (например, *"в следующий вторник в обед"*) и приведение их к фиксированному часовому поясу.
- **Async Architecture:** Полностью асинхронная обработка запросов и высокая пропускная способность за счет связки ASGI-сервера и современной экосистемы AnyIO/Uvicorn.

## 🛠️ Стек технологий

- **Language:** Python >= 3.11
- **Framework:** FastAPI, Starlette (Асинхронный бэкенд и маршрутизация)
- **AI / NLP:** OpenAI API (Интеграция LLM для понимания контекста)
- **Data Validation:** Pydantic v2 (Строгая типизация и валидация схем данных)
- **Date & Calendar Processing:** icalendar, parsedatetime, pytz
- **Async Engine:** AnyIO, Uvicorn (Стандарт со спец-расширениями httptools/uvloop)

## 📁 Структура проекта

Согласно архитектуре монорепозитория, проект разделен на два изолированных воркспейса:
- `/backend` — Высокопроизводительный веб-сервис (REST API) для обработки бизнес-логики.
- `/bot` — Интерактивный Telegram-бот, выступающий основным клиентским интерфейсом для пользователей.

## 📦 Быстрое развертывание

Проект управляется с помощью современного пакетного менеджера `uv`.

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd AI-Planner-Scheduler
   ```

2. **Настройте переменные окружения:**
   Создайте файл `.env` в корне проекта:
   ```env
   OPENAI_API_KEY=your_api_key_here
   TELEGRAM_BOT_TOKEN=your_bot_token_here
   ```

3. **Установите зависимости и запустите проект:**
   ```bash
   uv sync
   uv run uvicorn backend.main:app --reload
   ```
